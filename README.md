# 🚀 Jay Pawar - Developer Portfolio

A responsive, high-performance personal portfolio website showcasing full-stack projects, technical skills, and client connection portals. Built using HTML5, Tailwind CSS, and custom UI styling.

---

## 🌐 Live Demo

* **Live Website:** [portfolio-website-eta-seven-24.vercel.app](https://portfolio-website-eta-seven-24.vercel.app/)

---

## 🌟 Features

* **Modern Dark UI Theme:** Clean and minimalistic dark interface with blur animations and vibrant accents.
* **Responsive Layout:** Optimized across all device screen sizes (Mobile, Tablet, Desktop).
* **Project Showcase:** Highlights live web applications, open-source repositories, and system logic projects.
* **Profiles & Connect Section:** Clean 3-card layout linking directly to GitHub, LinkedIn, and Freelancer.
* **Direct Contact Hub:** Quick-access links for email and phone outreach.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS (via CDN)
* **Design/Styling:** Custom CSS animations, Tailwind Flexbox & Grid system
* **Hosting:** Vercel
